Import groupé

Choisis l'extension, puis dépose ses images. Chaque fichier est associé à l'image d'origine portant le même nom (ex. 17.png → la carte dont l'image s'appelait 17.png), quelle que soit son extension de fichier. Les images sont redimensionnées et converties en WebP dans ton navigateur avant l'envoi.

Sauvegardes Azure Blob

La base entière (tables, joueurs et images) est copiée automatiquement vers Azure Blob Storage. Pour restaurer : docker compose stop api, puis docker compose run --rm api npm run restore -- latest (ou le nom d'une sauvegarde), puis docker compose start api.

Nouvelle table

Lettres, chiffres et _, en commençant par une lettre. La table est créée vide ; ajoute ensuite ses colonnes dans « Structure ». Un workflow ne s'en sert que si son code y fait référence.

Renommer ou supprimer une colonne (ou une table) casse les workflows qui l'utilisent : la page te dit lesquels la mentionnent avant de valider. Changer le type reconvertit toutes les valeurs existantes (texte ↔ nombre, date ↔ texte, référence ↔ liste…).

Renommer ou supprimer la table

Clique sur une cellule pour la modifier (Entrée pour enregistrer, Échap pour annuler), sur un en-tête de colonne pour modifier sa structure. Les références s'écrivent avec l'id de la ligne visée ; les listes au format ["L", 1, 2].
